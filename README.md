# ☀️ Solar Power Generation Prediction from Weather Data

Regression / time-series project that predicts **solar power output** from changing environmental conditions (temperature, humidity, cloud cover, wind, time of day, season). Several models are compared, including a tuned **KNN regressor**, and the best one is served through a **Streamlit** app.

**Dataset:** [Renewable Power Generation and Weather Conditions](https://www.kaggle.com/datasets/pythonafroz/renewable-power-generation-and-weather-conditions) (Kaggle)

## Workflow

1. **Load** the CSV and auto-detect the timestamp and solar-power columns (override in `config.py`).
2. **Clean / engineer features:** weather variables plus hour, month, day-of-year and sin/cos cyclical encodings. Other power-output columns (e.g. wind) are dropped to avoid leakage.
3. **Chronological split:** first 80% of the timeline for training, last 20% for testing. No shuffling, so the model never sees the future.
4. **Models compared:** KNN Regressor, Linear Regression, Random Forest, Gradient Boosting, and a KNN tuned with `TimeSeriesSplit` cross-validation.
5. **Metrics:** MAE, RMSE, R².
6. **Deploy:** Streamlit app lets you choose weather conditions and a date/hour and returns the predicted power.

## Getting started

```bash
git clone https://github.com/<your-username>/Solar-Power-Generation-Prediction.git
cd Solar-Power-Generation-Prediction
pip install -r requirements.txt

# 1. download the dataset into data/ (see data/README.md)
# 2. train + evaluate + generate Excel report, plots and SQL files
python train.py

# 3. launch the app
streamlit run app.py
```

To explore step by step, open `solar_power_prediction.ipynb` in Jupyter.
